# 墨者 · Mohists

各有所长，协力成事。

墨者是 mdo 的可选多智能体协作插件。简单任务由协调者直接完成；复杂任务按需要分派给研究、执行与复核成员。成员保留自己的上下文，任务、定向消息、恢复与权限复用 mdo Application SDK。

## 本地开发

开发和测试只使用本仓库的一个运行目录，不创建隔离测试环境。默认引用同级 `../mdo` 的现有宿主和 SDK，仅部署约 9 MiB 的应用文件，可使用 `--mdo` 指定已有源码目录。

```powershell
python tools/dev.py setup
python tools/dev.py start
python tools/dev.py status
python tools/dev.py install
python tools/dev.py stop
```

`runtime/` 保存本项目的 mdo 配置、日志和 Home；不要提交账号、凭据或会话。开发实例只监听 `127.0.0.1`。安装插件需要按宿主规则重启实例。已有的用户 mdo 不受影响。
启动时会注册“墨者 · Mohists”项目，工作区直接绑定本仓库。自动测试使用同一个运行实例和 Home，不创建额外部署目录。
已有 mdo 源码需要包含 [mdo-runtime.json](mdo-runtime.json) 中的 SDK 基线；公开成员历史接口的宿主改动已独立提交到 mdo 主分支。

## 实现边界

- 普通可选 Agent，不替换全局默认 Agent。
- C 实现协作能力，配置与 Markdown 定义角色，原生前端 SDK 提供界面。
- 复用原生持久成员、共享任务、邮箱、CAS 状态、取消和恢复，不创建重复数据库。
- 单线程开发，每个可验证阶段提交到 `master`；测试也直接在项目运行目录顺序进行。
- 完整范围、阶段状态和待办见 [实施记录](docs/implementation.md)。

## 使用设置

选择墨者 Agent 后，从会话标题栏打开“墨者协作”。面板中的“默认设置”保存此设备所有项目共用的偏好：按需自动分工 / 仅用户从窗口开始、独立复核方式、并发、累计成员轮次，以及已安装 Agent/SubAgent 与模型绑定。

新任务组快照默认值；已经创建的任务组和成员不随全局编辑改变。“协作设置”可调整本组的预算、并发与复核方式，预算不清零；首次分派后角色和模型绑定固定。要求独立复核时，执行者的成功任务需有依赖该任务并成功完成的复核者，才能结束协作；协调者应在轮次预算内预留复核轮次。关闭自动复核仍允许用户明确要求复核。

成员详情中的“让此成员主讲”将之后的主输入交给该成员，沿用已有上下文，真实回复和工具记录显示在主聊天中。面板和聊天卡片显示当前主讲，可明确“返回协调者”。交接不更换全局 Agent，成员主讲仍受本组预算和权限约束。

## 源码分发

`python tools/package.py` 生成可复现的插件源码 ZIP 与 SHA-256 清单，体积约 60 KB，不包含开发 Home。解压后可在 mdo 插件页面导入目录。生态安装 JSON 需要显式指定兼容宿主的 `--min-build-id`；目前新增 SDK 仅有源码基线，尚未指定公开发布版本。

安装、更新、主讲和恢复的操作说明见 [使用指南](docs/user-guide.md)。源码分发、原生更新/回滚/停用/卸载/重装、创作中心导出及本地生态导入已在唯一开发实例实际验证；不会回滚或丢弃协作数据。

## 本地验收

`python tools/test.py` 顺序运行全部 21 组回归，已经在同一个开发 Home 通过；本地事实报告位于 `runtime/acceptance/full-regression.json`。覆盖真实协调者工具调用、成员多轮、取消恢复、主讲交接、权限与预算、远程目标协议组合、状态容量及插件分发生命周期。浏览器另行验收桌面与窄屏布局。模型请求仅使用本机确定性夹具，不代表供应商、安卓真机或真实双机测试。

含成员上下文的会话暂不支持完整便携迁移和多账本原子改写，宿主明确拒绝相应操作，避免静默丢失数据；完整边界见使用指南。本轮为本地功能交付，尚未发布兼容客户端到线上。
